# Wi-Fi and Network

> Invented information for a student project.

## Wi-Fi networks on campus
| Network name | Who can use it | How to log in |
|---|---|---|
| NBU-Secure | Students and staff | NBU ID number + NBU password (WPA2/WPA3-Enterprise) |
| NBU-Guest | Visitors | A guest code, valid 24 hours, requested by staff through ServiceHub |
| NBU-Setup | Anyone | Open network that only lets you reach the set-up page; use it if you cannot connect to NBU-Secure |

- Each NBU account can have up to 5 devices connected to NBU-Secure at the same time.
- Coverage: all classrooms, the library, the cafeteria and the dorms. There is no coverage
  in the parking areas or on the sports field.

## Connecting to NBU-Secure
**Windows 10/11:** Select NBU-Secure → enter NBU ID number and password → if asked to
"Continue connecting?" about a certificate, check that the server name is
radius.northbridge.example, then click Connect.

**Android:** Choose NBU-Secure → EAP method: PEAP → Phase 2: MSCHAPV2 →
CA certificate: "Use system certificates" → Domain: northbridge.example → Identity: your
NBU ID number → Password: your NBU password.

**iPhone / iPad:** Tap NBU-Secure → enter NBU ID number and password → tap Trust on the
certificate for radius.northbridge.example.

**Mac:** Choose NBU-Secure → enter NBU ID number and password → click Continue on the
certificate for radius.northbridge.example.

## Common Wi-Fi problems
| Problem | Try this |
|---|---|
| Password rejected after you changed your password | "Forget" NBU-Secure on the device and connect again with the new password |
| Connected but no internet | Turn Wi-Fi off and on; check that the date and time on the device are correct |
| Keeps disconnecting | Move closer to an access point; turn off "Private Wi-Fi address" only if IT asks you to |
| Too many devices | Remove an old device at https://devices.northbridge.example |
| Whole building has no Wi-Fi | Report it to the IT Desk as Urgent and say the building and room |

## Wired network (dorms and offices)
- Each dorm room has one wired port. Register your device's MAC address at
  https://devices.northbridge.example before plugging in.
- Game consoles and smart TVs cannot use NBU-Secure; register them for the wired port.
- Personal Wi-Fi routers are not allowed on campus because they interfere with NBU Wi-Fi.

## VPN (off-campus access)
- Use the NBU VPN to reach library databases and lab file shares from home.
- Download the VPN client from https://vpn.northbridge.example and log in with your NBU
  account plus MFA.
- The VPN is not needed for email, MyNBU or NBU Drive.
